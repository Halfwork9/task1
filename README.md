# 🚀 Personal Developer Portfolio

A modern, high-performance personal portfolio built for the **ShadowFox Beginner Level Task**. This project showcases my skills, experience, and real-world projects as a Full-Stack Developer in a clean, interactive, and fully responsive layout.

## 🌟 Features
* **Modern UI/UX:** Glassmorphism design with a soft color palette and ambient background glows.
* **Persistent Dark/Light Mode:** Seamlessly toggles and saves user preference via `localStorage`.
* **Dynamic Typewriter Effect:** Custom vanilla JavaScript typing animation highlighting core roles.
* **Interactive Project Filtering:** Easily filter projects by category (All, Full-Stack, Frontend, Backend/APIs).
* **Client-Side Form Validation:** Real-time validation for contact form fields (name, email, subject, character limit) with success toast notifications.
* **Responsive Design:** Mobile-first approach using Tailwind CSS, ensuring perfect rendering on phones, tablets, and desktops.
* **High Performance:** Lightweight single-file architecture with zero external heavy animation libraries (60fps native CSS/JS transitions).

## 🛠️ Tech Stack
* **HTML5** (Semantic structuring)
* **Tailwind CSS** (Styling, grids, typography, and responsive breakpoints)
* **Vanilla JavaScript** (DOM manipulation, theme toggling, form validation)
* **Lucide Icons** (Lightweight SVG iconography)

## 🚀 How to Run / Deploy
Because this project is built as a self-contained Single Page Application (SPA), no build steps are required.
1. Clone the repository.
2. Open `index.html` in any modern web browser to view the site locally.
3. **Deploy:** Simply upload the `index.html` file to GitHub Pages, Netlify, or Vercel for instant deployment.
